    AI Classification and Mapping of CTI into MITRE ATT&CK Techniques

    Research project, 2026 to 2027

    A research project that maps threat intelligence text to MITRE ATT&CK techniques with Transformer models, using STIX 2.1 alias-based data augmentation (CyberEDA).

    My partI trained and fine-tuned the classification models on the CTI datasets. My experiments measured how well EDA keeps the meaning and structure of the text, and checked that results stay stable across multiple seeds.

    DeleteCompressKeep

    AI-Driven Linux Disk Cleanup Assistant

    Team project, 2025 to 2026

    A Python tool that recommends Delete, Compress or Keep for each file, based on filename semantics (spaCy, Sentence-Transformers), size and file age. A Decision Tree makes the call, and safety guards (a system-path blacklist and trash-based deletion) keep it from doing damage.

    My partI built the desktop GUI (Tkinter) used to review and run the recommended actions.

    • Python
    • spaCy
    • Sentence-Transformers
    • Decision Tree
    • Tkinter
